# VR Fitness V11.14 Preview

## Neu
- Neuer Update-Dialog mit drei klaren Auswahlmöglichkeiten:
  - **Jetzt aktualisieren**
  - **Später erinnern**
  - **Diese Version überspringen**
- Übersprungene Versionen werden bei automatischen Prüfungen nicht erneut angeboten.
- Sobald eine neuere Version erscheint, wird wieder normal auf das Update hingewiesen.
- In den Einstellungen kann jetzt sichtbar festgelegt werden, ob VR Fitness beim Start automatisch nach Updates suchen soll.

## Verbesserungen
- Update-Entscheidungen bleiben vollständig beim Nutzer; VR Fitness erzwingt keine Installation.
- Eine manuelle Update-Prüfung kann auch eine zuvor übersprungene Version wieder anzeigen.
- Update-Dialog ist für Deutsch und Englisch vorbereitet.
- Installer-internen temporären Dateinamen von V11.12 auf V11.14 bereinigt.

## Hinweise
- **Jetzt aktualisieren** öffnet weiterhin den in `version.json` hinterlegten Download.
- **Später erinnern** fragt beim nächsten automatischen Update-Check erneut.
- **Diese Version überspringen** gilt nur für die konkret angebotene Version.
- V11.14 bleibt zunächst Preview und sollte vor der öffentlichen Freigabe getestet werden.
