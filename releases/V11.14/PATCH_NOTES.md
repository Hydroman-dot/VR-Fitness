# VR Fitness V11.14 Preview

## Deutsch

### Neu
- Neuer Update-Dialog mit drei klaren Auswahlmöglichkeiten:
  - **Jetzt aktualisieren**
  - **Später erinnern**
  - **Diese Version überspringen**
- Übersprungene Versionen werden bei automatischen Prüfungen nicht erneut angeboten.
- Sobald eine neuere Version erscheint, wird wieder normal auf das Update hingewiesen.
- In den Einstellungen kann festgelegt werden, ob VR Fitness beim Start automatisch nach Updates suchen soll.

### Verbesserungen
- Update-Entscheidungen bleiben vollständig beim Nutzer; VR Fitness erzwingt keine Installation.
- Eine manuelle Update-Prüfung kann auch eine zuvor übersprungene Version wieder anzeigen.
- Update-Dialog ist für Deutsch und Englisch vorbereitet.
- Installer-interner temporärer Dateiname wurde auf V11.14 bereinigt.

### Hinweise
- **Jetzt aktualisieren** öffnet den in `version.json` hinterlegten Download.
- **Später erinnern** fragt beim nächsten automatischen Update-Check erneut.
- **Diese Version überspringen** gilt nur für die konkret angebotene Version.
- V11.14 bleibt Preview und sollte weiter getestet werden.

## English

### New
- New update dialog with three clear choices:
  - **Update now**
  - **Remind me later**
  - **Skip this version**
- Skipped versions are no longer shown during automatic checks.
- When a newer version becomes available, it will be offered normally again.
- Settings now include a visible option to enable or disable automatic update checks at startup.

### Improvements
- Update decisions remain fully under the user's control; VR Fitness never forces an installation.
- A manual update check can still show a version that was previously skipped.
- The update dialog is prepared for both German and English.
- The installer's internal temporary filename was cleaned up for V11.14.

### Notes
- **Update now** opens the download configured in `version.json`.
- **Remind me later** asks again during the next automatic update check.
- **Skip this version** applies only to the specific version currently offered.
- V11.14 remains a Preview build and should continue to be tested.
