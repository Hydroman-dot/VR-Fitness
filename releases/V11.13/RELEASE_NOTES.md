# VR Fitness V11.13 Preview

## Änderungen

- Einstellungen werden versionsunabhängig unter `%LOCALAPPDATA%\VR Fitness\vr_fitness_config.json` gespeichert.
- Vorhandene Einstellungen aus älteren Installationen werden bei V11.13 automatisch übernommen.
- Bestehende Konfigurationswerte werden bei Updates ergänzt statt überschrieben, damit Haken, Datumswerte, Quellen, Health-Connect-Einstellungen, Pfade und weitere Optionen erhalten bleiben.
- Sprachsystem ergänzt: Systemsprache, Deutsch oder English manuell auswählbar.
- Sprachwahl wird gespeichert und beim nächsten Start vollständig angewendet.
- Update-Quelle auf `Hydroman-dot/VR-Fitness` umgestellt.
