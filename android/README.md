# VR Fitness Android Companion

Dieser Ordner ist für die Android-App / den Health-Connect-Companion von VR Fitness vorgesehen.

## Zweck

Die Android-App verbindet VR Fitness auf dem PC mit Android Health Connect und kann außerdem lokale Statusdaten für den PC bereitstellen.

## Aktueller Stand

Die Android-App befindet sich noch im Test-/Previewbetrieb und wird vorerst direkt über GitHub verteilt.

## Geplante Inhalte

- APK-Dateien der jeweiligen Version
- Quellcode bzw. Android-Studio-Projekt
- Patchnotes / Versionshinweise
- Hinweise zur Installation und zu benötigten Berechtigungen

Bis zu einer möglichen späteren Veröffentlichung im Google Play Store bleibt GitHub der primäre Ablage- und Download-Ort.
